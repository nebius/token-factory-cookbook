# Nebius Token Factory edition

This fork preserves the original application's functionality and credits its original builder. It changes the interface to the official Token Factory navy/lime palette, Gramatika display type and Inter UI type, with the official logo and self-hosted fonts.

Original source: https://github.com/shivaylamba/explode-anything

Design source: Token Factory Design v1.0.0, published commit 377dd51058afd17818439cd6113f486381386992.

Original builder: Shivay Lamba. Nebius permission to adapt and publish confirmed directly by Dylan Bristot on 5 November 2026. No blanket open-source licence is added to the original work.
