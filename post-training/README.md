# Post-training

Adapt model behavior for a specific task with Nebius Token Factory. Follow the recipe for dataset preparation, training configuration, and evaluation.

| Recipe | Focus |
| --- | --- |
| [Fine-tuning Meta-Llama-3.1](fine-tuning-1/) | Prepare data, configure a fine-tuning job, and evaluate the result |
| [Gemma 4 for efficient agentic coding](gemma-4-agentic-coding/) | Distill Kimi-K3 and DeepSeek-V4.1-Flash coding-agent runs into a Gemma 4 LoRA, then measure the change on held-out repositories |

For a related adaptation workflow, see [distillation](../distillation/README.md). For current platform features and supported models, use the [official post-training documentation](https://docs.tokenfactory.nebius.com/post-training/overview).
