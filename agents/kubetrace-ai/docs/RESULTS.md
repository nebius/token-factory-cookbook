# Results

Generated by `scripts/results_table.py` from the run database on 2026-10-16. **Every investigated attempt is included**, failures and infrastructure errors too (an `error` outcome below; causes in "Infrastructure errors"). Runs that failed in setup before any investigation started, including several from while the harness itself was being debugged, stay in the database but are not agent outcomes and are not tabulated.

- **Live** runs call **Muse Spark Open** (`meta-models/muse-spark-open`) on Nebius Token Factory. They are **not Beam**; Beam isn't in the Token Factory catalog yet, so live Beam verification is pending.
- **Fixture** runs use a scripted test double. They show that the pipeline and the hidden checks work end to end, and say nothing about a model.
- These are six small demo scenarios, one or two runs each. They are **not** a benchmark, and not comparable to SWE-bench or Terminal-Bench.
- Some run metrics were **reconstructed from recorded events**, because the headless runner exited before saving them (fixed). Their reports say so.
- Cost is an **estimate** from provider-reported tokens at the catalog rate for Muse Spark Open ($1.25 / $4.25 per M input/output tokens, read from `GET /v1/models?verbose=true` on 2026-10-16), with no cached-token discount applied.
